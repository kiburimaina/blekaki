# Blekaki

**Discover. Shop. Sell. Become.**
A Kenya-first, international-ready marketplace, independent store builder, dropshipping and wholesale network, and entrepreneurship platform.

## Status
Milestone 0: project foundation (documents only, no application code yet).

## Stack
Next.js (App Router), React, TypeScript, Tailwind CSS, shadcn/ui, Supabase (Postgres, Auth, Storage, Row Level Security), Vercel, GitHub.

## Milestones
0 Foundation · 1 Premium shopping experience · 2 Auth and marketplace · 3 Seller business system · 4 Supplier and wholesale network · 5 Payments and ledger · 6 Fulfilment and logistics · 7 Marketing and AI studio · 8 Business management · 9 Platform administration · 10 Internationalisation · 11 Full QA and launch readiness

## Working rules
- This repository is the source of truth. Inspect before changing existing files.
- Work on feature branches. No merge to `main` without approval.
- No deployment, live payments or paid services without explicit approval.
- No secrets in code. No fake production data, reviews, stock numbers or verification badges.
- A feature is finished only when it has working logic, database operations, permissions, validation and tests.
