# Design system: warm luxury

## Colour tokens
| Token | Light | Dark |
|---|---|---|
| ivory (background) | #FAF6EE | #1D1B18 |
| cream (surface) | #F1E9DA | #26231F |
| beige (lines, fills) | #DDD1BC | #3A352D |
| ink (text) | #26231F | #F3ECDD |
| ink-soft (secondary text) | #5B554C | #B9AF9D |
| gold (text/accents) | #8F6E2E | #D4B574 |
| gold-fill (buttons) | #C9A862 | #C9A862 |
| sage (success/trust) | #5E6F5A | #9DB097 |

Use gold sparingly. Gold text must meet WCAG AA contrast against its background.

## Typography
Display: Newsreader (serif). Body and UI: Instrument Sans. Fallbacks: Georgia and system-ui.

## Principles
Editorial layouts, generous whitespace, few borders, one clear primary action per view, refined motion that respects reduced-motion settings.

## Components to build (Milestone 1 onward)
Buttons, cards, product gallery, navigation, forms, filters, dialogs, notifications, dashboard components, loading, empty and error states. All use these tokens and nothing else.
